# TrafficVision AI

TrafficVision AI is a full-stack traffic and road monitoring system that uses
computer vision to detect, track, count, and analyze vehicles in traffic videos.

## Planned Pipeline

```text
Traffic video
    ↓
Vehicle detection
    ↓
Vehicle tracking
    ↓
Vehicle counting
    ↓
Speed estimation
    ↓
Traffic density
    ↓
Violation detection
    ↓
React dashboard
